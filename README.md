# Школьная столовая

Простая система управления питанием в школе.

## Запуск:
1. Установи Node.js
2. В папке backend: `npm install`
3. Запусти: `npm start`
4. Открой: http://localhost:3000

## Функционал:
- Вход для учеников, поваров, администраторов
- Просмотр меню
- Симуляция заказа# AIS-Shkolnoe-pitanie-
